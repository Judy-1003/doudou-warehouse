豆豆小仓库

一个只给自己用的咖啡记账本 —— 记录每天喝的咖啡，管理咖啡豆和辅料库存，自动算成本和营养。原生微信小程序，数据存在本地，不需要服务器。

微信小程序 TypeScript 本地存储 自用工具

核心是三件事

① 记一杯

选品类、选温度（热/常温/冰）、选豆子、选辅料，自动算钱和营养，一键保存。

② 管库存

咖啡豆和牛奶/椰子水都有余量，喝一杯扣一杯，删记录会自动归还。

③ 看统计

每天/每周/每月喝了多少、花了多少钱，日历一目了然，点哪天都能查看和改。

首页 —— 今天喝什么

  • 选品类拖拽排序后的前 3 个品类 + "其他"，温度单独选（热 / 常温 / 冰）
  • 选豆子按余量比例显示进度条，选中后自动扣库存
  • 调用量用豆量支持现场加减或直接输入，不用去设置改默认值
  • 选辅料牛奶/椰子水/自定义饮品联动库存，扣完会提示余量不足
  • 保存拍照、评分，成本和咖啡因/蛋白质/脂肪/糖分实时算好
  • 咖啡日历小圆点标记有记录的日期，点进去能看那天的所有记录并左滑删除/修改

仓库 —— 豆仓 / 饮品架

  • 豆仓按"正在喝 / 未启封 / 已归档"分组，显示余量进度条、赏味期状态、预计还能喝几天
  • 长按删除豆子或辅料卡片长按即可删除，5 秒内可撤销
  • 存放方式未启封的豆子可直接"转常温 / 转冷冻 / 启封"
  • 补满饮品架每个物料显示余量和大概还能做几杯，一键补满整瓶容量

个人设置

功能说明
咖啡品类管理长按拖拽排序，前 3 个直接展示在首页，其余收进"其他"
默认消耗量豆子每次用多少克、牛奶/椰子水每次用多少毫升
豆子清单只看喝过的豆子，含杯数和评分
数据统计周/月/年三种视角，花费、豆子消耗、日均用量，每日明细可跳转查看/修改
初始化数据支持"只清空记录"（物料自动归还）或"全部初始化"（恢复出厂设置）

技术实现

原生小程序

TypeScript + WXML + WXSS，微信开发者工具直接导入即可运行，无需额外构建工具链。

本地持久化

数据全部存在 wx.setStorageSync 本地缓存里，不需要服务器和后端配置。

模块化业务逻辑

services/storage.ts 管数据读写，services/logs.ts 管记录增删改和库存归还，utils/calculations.ts 管所有计算。

pages/home 首页 pages/warehouse 仓库 pages/settings 设置 pages/categories 品类排序 pages/bean-detail 豆子详情 pages/day-logs 当天记录 pages/statistics 统计
数据存在当前设备的微信本地缓存里，换手机或清除小程序数据会导致数据丢失，不会自动同步。想要多设备同步，需要接入微信云开发，代码结构已经把持久化逻辑单独抽出，替换起来改动量不大。
